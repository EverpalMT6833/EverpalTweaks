🌟 HyperOS Leica Camera v6 for POCO M4 Pro 5G / Redmi Note 11S 5G (everpal) 🌟
⚡ Android 16 (Project Infinity / LineageOS 23.0) Bringup & Full Production Release

Hey everyone! After extensive reverse engineering, debugging, and bytecode surgery, I have officially brought up and fully stabilized the HyperOS Leica Camera v6 port on Android 16 for the MediaTek Dimensity 810 (MT6833/MT6833P) platform!

Every major blocker—from dark preview viewfinders to night mode capture errors and sluggish mode transitions—has been empirically solved and verified live on-device.

🔥 WHAT'S NEW & WHAT WE FIXED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ☀️ Fixed Pitch-Black / Dark Viewfinder (AE Routing Fix):
   • Issue: The preview viewfinder was dark/pitch black in all camera modes because MediaTek's CCU hardware sensor interface failed to return auto-exposure statistics on AOSP.
   • Fix: Routed MediaTek's 3A engine (lib3a.ae.stat.so) directly to CPU-calculated AE via vendor.debug.ae.stat.type=2. Preview is now crystal-clear, bright, and naturally exposed in all lighting conditions.

2. ⚡ Instant & Fluid Mode Switching (Zero-Stutter Transitions):
   • Issue: Switching between modes had severe delays (600ms–1500ms) with noticeable UI freezes and frame drops.
   • Root Causes Identified & Eliminated:
     - MIVI Polling Loop: Bypassed the offline session polling loop in OfflineSessionManager (isSessionOffline() -> true), terminating the recurring 10ms postDelayed loop that stacked artificial pauses on AOSP.
     - GPU Shader Readback Stalls: Disabled the heavy 26-frame multi-pass fullscreen Gaussian blur animation (switchModeAnimRender) on the Mali-G57 MC2 GPU.
     - Mode Selector Lock: Zeroed the post-delayed accessibility timer in FragmentModeSelector.
   • Result: Instantaneous, fluid mode switching between Photo, Video, Portrait, Documents, and Night in under 250ms with zero stutter.

3. 🌙 Night Mode Fully Operational & Fixed:
   • Issue: Night mode opened, but pressing the shutter triggered "Can't connect to camera" and failed to save photos.
   • Fix: Patched NightModule bytecode (getRawCallbackType = 0x10) and injected null-safe branching in ba/u1 to prevent null ImageReader surface dereferencing. Night mode now captures and writes complete JPEGs with authentic Xiaomi EXIF metadata (OpMode: 36869, NightScene=1).

4. 📸 Leica Color Science & Authentic / Vibrant Engine:
   • Full Leica Authentic and Leica Vibrant color grading profiles active.
   • Master Portrait lenses with physical bokeh depth sensor routing (Camera @3).
   • Document scanner with automatic real-time yellow polygon border detection.

5. 🛡️ Android 16 Bionic ABI & Alignment Fixes:
   • Repacked all native 64-bit binaries into Android Bionic's canonical lib/arm64-v8a/ directory.
   • Packaging sanitized to uncompressed ZIP_STORED (method 0) to avoid Android 16 AssetManager file-descriptor deflation crashes.
   • Byte-aligned to 4-byte boundaries with zipalign and cryptographically signed with APK Signature Scheme v3.
