## Device Tree Integration Complete ✅

The Leica Camera v6 EverpalTweaks fixes are now a proper build-time device tree — no KernelSU module required at source-build time.

### What Was Integrated

#### vendor/xiaomi/camera-everpal (camera)

• MiuiCamera.apk — Updated to the fully patched MiCam-signed.apk (md5: c0d0508d…) containing all 6 fix layers
• Android.bp — Already declares android_app_import with preprocessed: true + all JNI .so modules
• miuicamera.mk — Already copies permissions XMLs, hiddenapi whitelist, public.libraries-xiaomi.txt, and sets ro.product.mod_device=evergo_in_global
• miuicamera.te — Already has allow priv_app same_process_hal_file, hal_misys_hwservice, vendor camera prop access

#### device/xiaomi/everpal (vendor.prop)

• Added persist.vendor.camera.privapp.list=com.android.camera under the # Camera section (line 61) — whitelists Leica Camera as a privileged HAL-binding process

### How It Works at ROM Build Time

repo sync
  # device.mk line 7: $(call inherit-product-if-exists, vendor/xiaomi/camera/miuicamera.mk)
  # → PRODUCT_PACKAGES += MiuiCamera (the patched APK)
  # → PRODUCT_SYSTEM_PROPERTIES += ro.product.mod_device=evergo_in_global
  # → BOARD_VENDOR_SEPOLICY_DIRS += vendor/xiaomi/camera/sepolicy/vendor
  # → configs/props/vendor.prop → persist.vendor.camera.privapp.list=com.android.camera
  make lineage_everpal-userdebug
